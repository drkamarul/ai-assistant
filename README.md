# Smart Data Analysis in Health and Medicine — workshop website

Public website for participants: https://smart-analysis-drph.netlify.app

- `index.html` — the landing page (programme, before-you-come checklist, download links)
- `slides/` — rendered Quarto revealjs decks (Topics A–D)
- `notes/` — rendered hands-on notes and the setup guide

The HTML files are rendered copies. The Quarto sources live in KIM's workshop folder
(`slides/*.qmd`, `notes/*.qmd`). To update the site: re-render there, copy the `.html`
files into `slides/` and `notes/` here, commit and push.

Starter zips and the dataset are shared from Google Drive:
https://drive.google.com/drive/folders/1VDWzxGIc9EciOzNeMm9zAHS8sS9EMDfC?usp=sharing
